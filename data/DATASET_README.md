# 数据集说明（cases_dataset.json · 30 例）

## 这批案例是怎么来的

**全部为依据法律条文与执法文书格式构造的「真实场景改写案例」，证据等级〔合成〕。**
没有复制任何真实处罚决定书的原文；人名一律「某」、号牌部分遮蔽。

为什么不用真实文书直接抓取：

| 渠道 | 现状 | 结论 |
|---|---|---|
| 裁判文书网 | 需登录、验证码、严格反爬 | 脚本化抓取不可行，也不建议绕过 |
| 信用中国 | 公开接口有 JS 质询反爬 | 同上 |
| 北大法宝 / 威科先行 | 校园渠道可检索导出 | **推荐路径**：导出 .txt → `tools/import_real_cases.py` 清洗脱敏 → 并入 `real_cases.json` |

因此本数据集承担两个角色：演示与冒烟测试；以及作为真实数据导入后的**格式模板**。

## 构成

30 例，覆盖 4 类行为 × 6 类审查焦点：

| 行为 | 数量 | 覆盖焦点 |
|---|---|---|
| 超速 | 10 | 合规基准、裁量、设备检定、录入/告知时限、首违不罚、顶格、幅度、脏数据、要素缺失 |
| 违停 | 8 | 合规基准、拒绝驶离前提、要素残缺、送达超期、一事不再罚、首违不罚、幅度、脏数据 |
| 闯红灯 | 5 | 合规基准、证据清晰度、设备故障抗辩、幅度、多次违法 |
| 未系安全带 | 4 | 合规基准、违法主体定性、首违不罚、幅度 |
| 手持电话 | 3 | 定性边界、裁量、无客观记录的现场执法 |

## 真实数据导入流程（待办）

1. 通过校内渠道（北大法宝等）检索目标行政处罚决定书，导出为 .txt，每案一个文件；
2. 放入 `data/raw_cases/`；
3. 运行 `python tools/import_real_cases.py`；
4. **人工复核脱敏效果**（脚本按保守规则遮蔽，但机器不承担法律责任）；
5. 复核通过后再并入评测集或对外分享。
